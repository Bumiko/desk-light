# Куда идём

## Сейчас
1. Прошить плату MicroPython, залить `firmware/main.py`, получить `PONG` через `app/cli.py`.
2. Пайка по `docs/WIRING.md`, проверка ленты от слабой яркости к максимуму.
3. Приложение в трее: горячие клавиши, уровни яркости, запоминание последней, автозапуск.

## Полки

### Удобство
- Вечером тусклее: разные уровни по времени суток.
- Восстанавливать свет после выхода ноутбука из сна, если он был включён.
- Собрать в один exe вместо python + ярлык в автозагрузке.

### Железо
- Вторая лента (например, за монитором) — второй канал ШИМ и номер канала в протоколе.
- Датчик освещённости: включать саму, когда в комнате темно.

### Не сейчас
- Wi-Fi и управление с телефона — это другая плата (ESP32) и другая прошивка.
  Смысл появится, только если лент станет много и они разъедутся по комнате.
