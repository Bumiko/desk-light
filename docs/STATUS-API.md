# Сводка сервера: что должен отдавать `/status`

Экран показывает состояние сервера. Приложение само на сервер не заходит: раз в три
секунды оно забирает один JSON по адресу из `%LOCALAPPDATA%\desk-light\config.json`:

```json
{"status_url": "http://<адрес сервера>:8787/status"}
```

Служба на сервере — отдельная вещь и в этом репозитории не лежит: она знает устройство
конкретной машины. Свою можно написать на чём угодно, лишь бы ответ был такой:

```json
{
  "host": "gpu-server",
  "time": 1791569999,
  "uptime_s": 1662345,
  "api_ok": true,
  "cpu_load": 12,
  "cpu_temp": 34.5,
  "gpu": {"load": 34, "mem_used_mb": 5200, "mem_total_mb": 12227, "temp": 52, "watts": 140},
  "queue": {"queued": 2, "running": 1, "workers": 1},
  "meetings": {"agents": 1, "max": 3},
  "today": {"hours": 14.7, "clients": 4},
  "units": {"asr-api": true, "asr-tunnel-front": true, "telemost-orchestrator": true, "fanctl": true},
  "backup": {"ok": true, "finished": "Fri 2026-10-09 03:30:35 MSK"},
  "errors": []
}
```

## Правила
- Любое поле может быть `null` или отсутствовать: на экране на его месте будет прочерк,
  лампочка станет серой. Сломался один источник — остальная сводка должна прийти.
- `api_ok` красит точку у имени сервера. `units` и `backup.ok` — лампочки внизу экрана:
  зелёная, красная или серая (нет данных).
- `time` — часы сервера, секунды с 1970 года. Показывается в шапке как время сводки.
- Ответ нужен быстрее 2,5 секунды. Сводки нет дольше 15 секунд — на экране «нет связи
  с сервером» и время последней удачной: застывшие цифры за живые не выдаём.
- Какие имена служб и какие плитки показывать, задаёт `to_view` в `app/server_screen.py`.
